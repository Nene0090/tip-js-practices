## Запуск

Запуск осуществляется в двух терминалах из папки `practice-08`:
1. Сервер API: `npm run api` (доступен по адресу http://127.0.0.1:5505/api)
2. Клиент: `npm run dev` (доступен по адресу http://127.0.0.1:5173/)

## Компоненты и данные
- `App.jsx` — владелец состояния фильтров и редактируемой задачи. Вызывает хук `useTaskData` и передает данные вниз.
- `useTaskData.js` — кастомный хук. Управляет тремя состояниями: `snapshot` (данные), `status` (isLoading/error/ready) и `error`. Содержит эффект загрузки с `AbortController`, защиту от устаревших ответов (флаг `active`) и общую функцию `mutate` для POST/PATCH/DELETE.
- `api-client.js` — обертка над `fetch` с обработкой тайм-аутов и ошибок.
- `task-api.js` — предметный API (методы `loadInitialData`, `createTask`, `updateTask` и т.д.).

## Сценарий варианта 6
Начальный фильтр: `categoryId=2` («Проект»).
Сценарий: создать задачу категории «Проект», перезагрузить страницу и найти её.
